# Packaging

Packages contain `flattencom-gui`, `flattencom`, `flattencomd` and `flattencom-mcp`, plus the Qt runtime when deployment is enabled. The [development guide](../docs/DEVELOPMENT.md) lists prerequisites and package commands. The package script uses explicit CMake commands and requires CMake 3.24+; the presets in `gui/CMakePresets.json` require 3.25+.

The systemd user unit is in `systemd/`. See [Windows packaging](windows/README.md) for runtime deployment. `scripts/package.py` writes checksums for the artifacts generated by its current invocation; older files can still be present in `dist/`.
